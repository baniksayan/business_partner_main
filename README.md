# Business Partner Dashboard - Flutter Project

## Overview
A Flutter-based business dashboard using MVVM architecture for partners (like Uber/JustDial).

## Tech Stack
- **Flutter**, **MVVM**
- **Provider** (State)
- **GetIt + Injectable** (DI)
- **Dio + Retrofit** (Networking)
- **SharedPreferences / SQLite** (Storage)

## Features
- Dashboard analytics
- Product/service CRUD
- Customer & wishlist management
- Push notifications
- Profile, business hours
- Multi-language support

## Key Packages
- `provider`, `get_it`, `injectable`
- `dio`, `retrofit`, `connectivity_plus`
- `fl_chart`, `lottie`, `shimmer`
- `firebase_messaging`, `qr_flutter`, `pdf`

## Screens
- **Auth**: Splash, Login, Reset
- **Dashboard**: Charts, Actions
- **Modules**: Products, Services, Customers
- **Settings**: Profile, Language, Hours

## Testing
- Unit, widget, integration tests
- Mock repositories for logic testing

## Collaboration
- Modular codebase
- Clean separation of logic and UI
- Backend-ready structure
